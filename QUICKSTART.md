# Quick Start Guide

## First Time Setup (2 minutes)

1. Extract the CTP_Tracker_Complete folder
2. Open Command Prompt
3. Navigate to the folder: cd C:\path\to\folder
4. Run: python ctp_tracker.py
5. Select option 5: Setup Email Configuration
6. Fill in email addresses for: sender, recipient, cc
7. Select option 6: Install Dependencies
8. Wait for installation to complete

## Daily Usage

1. Install outlook app and sign in to email
2. Run: python ctp_tracker.py
3. Log your work (option 1)
4. Send email (option 4)
5. Review in Outlook and click Send

## Tips

- Press 0 at any menu to go back
- Paste file paths with quotes: "C:\file.py" (select file press key combo CTRL+SHIFT+C)
- Entries from yesterday auto-clear
