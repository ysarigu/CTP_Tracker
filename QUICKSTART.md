# Quick Start Guide

## First Time Setup (2 minutes)

1. Extract the CTP_Tracker_Complete folder
2. Open Command Prompt
3. Navigate to the folder: cd C:\path\to\CTP_Tracker_Complete
4. Run: python ctp_tracker.py
5. Select option 4: Install Dependencies
6. Wait for installation to complete

## Daily Usage

1. Keep Outlook running
2. Run: python ctp_tracker.py
3. Log your work (option 1)
4. Send email (option 3)
5. Review in Outlook and click Send

## Tips

- Press 0 at any menu to go back
- Paste file paths with quotes: "C:\file.py"
- Keep Outlook open when sending emails
- Entries from yesterday auto-clear
